Crack Detection and Assessment Using Computer Vision Intelligence

Student Janarthana Prabu S · CB.SC.P2AIE25007 Guide Dr. Padmavathi S, Associate Professor Dept. Computer Science & Engineering, Amrita Vishwa Vidyapeetham
SDNET2018UAV-GCDGLOH · HOG · SURF · BRISK · MSERSVM · RF · XGBoost · DTRaspberry Pi · edgeOpenCV · Hough

Heavy deep-learning crack detectors need GPUs that low-cost inspection hardware does not have. This project replaces them with engineered image features and classical classifiers that run on a CPU, and tests that idea on public concrete datasets, aerial drone imagery and a Raspberry Pi live camera.

56,092SDNET2018 images used
132models trained (11 features × 4 classifiers × 3 tasks)
87.06%best 3-class accuracy (Spatial HOG + SVM)
72.67%best binary accuracy (GLOH + Random Forest)
17papers in literature survey

Objectives

  1. Quantify how the choice of descriptor changes accuracy, precision, recall and F1 for crack classification.
  2. Find the best classical classifier for each feature representation and task level.
  3. Compare global (patch-free) and local (grid-patch) feature extraction for crack screening versus component identification, and measure how accuracy falls as classes grow from two to six.
  4. Benchmark these lightweight pipelines against deep-learning work such as CrackVision and DTrC-Net.
  5. Validate on real aerial drone imagery (UAV-GCD) with edge-map and Hough-transform analysis of linear cracks.
  6. Demonstrate live crack inspection on CPU-only edge hardware (Raspberry Pi).

Two-phase approach

Phase 1 · Classification baseline

A multi-tier benchmark on SDNET2018: binary crack detection, three-class component identification (deck / pavement / wall) and a six-class joint task. Eleven feature configurations feed four classifiers.

Phase 2 · Aerial validation

Road-surface extraction, multi-detector edge maps and a ranked polar Hough analysis on UAV-GCD drone images, plus annotation overlays and binary masks from the dataset's JSON labels.

Project

Problem statement and research gap

Problem statement

Detect cracks in live videos using computer vision intelligence on edge devices.

Input

  • Source: live video stream from a camera such as a Raspberry Pi camera, a drone or a handheld device.
  • Data: continuous RGB frames (256 × 256) of concrete walls, bridge decks and pavements.

Output

  • Frame-by-frame detection: crack classification on every live frame.
  • Structural categorisation: surface type (wall, deck or pavement).
  • Live alerting: on-screen overlays and text labels for maintenance operators.

Research gaps

GapWhat the literature shows
High computational costCNNs, transformers and ViTs need high-end GPUs. Real-time inference on low-cost edge CPUs such as a Raspberry Pi is not practical.
Environmental sensitivityClassical image processing and standard CNNs produce false positives from shadows, lighting changes, formwork lines and surface moss.
Narrow domain focusMost studies train on one surface type (only pavements, or only walls) and do not generalise across surfaces.
No structural contextMost methods stop at crack / no crack and do not name the component (bridge deck, wall or pavement).
Class imbalanceSDNET2018 holds roughly 85% uncracked and 15% cracked images, which lowers classical-model precision unless features are engineered for it.

Phase 2 pipeline (aerial imagery)

  1. Road extraction: BGR → HSV, threshold the saturation channel (T = 50), invert, then open / close / erode with a 7 × 7 kernel and keep components above 1,000 px.
  2. Enhancement: mask the road, apply CLAHE (clip limit 3.0, 8 × 8 tiles) and a 3 × 3 Gaussian blur.
  3. Multi-detector edges: Sobel gradient magnitude (T = 40) or Canny (50 / 150), plus Laplacian, with gradient-angle maps and histograms.
  4. Ranked Hough analysis: polar Hough transform (ρ = 1 px, θ = 1°) over five accumulator bands, with line length, width and thickness metrics.
  5. Verification: overlay the dataset's JSON ground truth next to the original image and prepare precision and mAP scoring.

Method

Algorithms, mathematical model and evaluation metrics

Feature descriptors

Combined vector (205-D)

Sobel gradients give magnitude and orientation. Per region, five statistics of the edge magnitude are joined with a 36-bin orientation histogram (41-D); the whole image and four grid cells are concatenated.

|∇I(x,y)| = √(Ix² + Iy²) θ(x,y) = arctan(Iy / Ix) stats = [μ, σ, σ², skew, kurt] of |∇I| region = [stats, 36-bin angle histogram] (41-D) v = [region(image), region(cell1..4)] (205-D)

Spatial HOG

Gradient magnitudes vote into orientation bins inside each grid cell c.

H(c) = Σ p∈c |∇I(p)| · δ(θ(p) − b)

Shi-Tomasi corners

Corner score is the smaller eigenvalue of the gradient structure tensor M; keypoints are taken over the frame or per grid cell.

R = min(λ1, λ2)

MSER

Regions that stay stable over threshold changes ±Δ, useful for small low-contrast cracks.

Ψ(Rt) = |R(t+Δ) \ R(t−Δ)| / |Rt|

SURF

Blob response from box-filter approximations of the Hessian determinant.

det(Happrox) = Dxx·Dyy − (0.9·Dxy)²

BRISK

Binary descriptor from smoothed intensity comparisons on a circular sampling pattern.

bi = 1 if I(pi) > I(qi), else 0

GLOH (128-D)

Gradient magnitudes pooled into 17 log-polar spatial regions and orientation bins, then quantised against a 128-word codebook.

G(ρ,θ) = Σ |∇I| · δ(ρbin, θbin)

Classifiers

Support Vector Machine

min ½‖w‖² + C Σ ξi s.t. yi(wᵀφ(xi)+b) ≥ 1 − ξi, ξi ≥ 0

RBF kernel, soft margin.

Decision Tree

IG(D,A) = H(D) − Σ v (|Dv|/|D|) · H(Dv)

Single CART baseline with Gini impurity.

Random Forest

Ĉ(x) = argmax k Σ b=1..B I( Tb(x) = k )

Bootstrap-aggregated trees, majority vote.

XGBoost

L(t) ≈ Σ [ gi·ft(xi) + ½·hi·ft²(xi) ] + Ω(ft)

Gradient-boosted trees, histogram split builder.

Evaluation metrics

Metrics are computed on the held-out test set. Multi-class scores are macro-averaged so that every class counts equally.

Accuracy = (TP + TN) / (TP + TN + FP + FN) Precision = TP / (TP + FP) Recall = TP / (TP + FN) F1 = 2 · Precision · Recall / (Precision + Recall) Balanced accuracy = mean recall over classes

Resource metrics for edge feasibility are CPU inference latency (ms per image), peak RAM (MB) and stored model size (MB). Phase 2 adds ground-truth overlay checks, precision and mAP, and line metrics (length, width, thickness) from the Hough analysis.

    # Helper function for drawing standard polar Hough lines by rank slices
    def draw_polar_line_range_with_metrics(base_img, binary_edges, lines, start_rank, end_rank, color=(255, 0, 0)):
        overlay = base_img.copy()
        if lines is None or len(lines) == 0:
            return overlay, 0, 0.0, 0.0, 0.0

        actual_start = min(start_rank - 1, len(lines))
        actual_end = min(end_rank, len(lines))

        if actual_start >= actual_end:
            return overlay, 0, 0.0, 0.0, 0.0

        selected_lines = lines[actual_start:actual_end]
        count = 0
        total_length = 0.0
        total_width = 0.0
        total_thickness = 0.0

        for line in selected_lines:
            rho, theta = line[0]
            a = np.cos(theta)
            b = np.sin(theta)
            x0 = a * rho
            y0 = b * rho

            x1 = int(x0 + 10000 * (-b))
            y1 = int(y0 + 10000 * (a))
            x2 = int(x0 - 10000 * (-b))
            y2 = int(y0 - 10000 * (a))

            cv2.line(overlay, (x1, y1), (x2, y2), color, 2)

            mask_line = np.zeros_like(binary_edges)
            cv2.line(mask_line, (x1, y1), (x2, y2), 255, 1)
            intersection = cv2.bitwise_and(binary_edges, binary_edges, mask=mask_line)

            active_pixels = np.column_stack(np.where(intersection > 0))
            if len(active_pixels) > 1:
                pts = active_pixels[:, [1, 0]]
                dists = [np.linalg.norm(pts[i] - pts[j]) for i in range(len(pts)) for j in range(i+1, len(pts))]
                line_len = max(dists) if dists else 0.0
            else:
                line_len = 0.0

            line_area = np.sum(intersection > 0)
            line_width = line_area / line_len if line_len > 0 else 0.0
            line_thick = line_width

            total_length += line_len
            total_width += line_width
            total_thickness += line_thick
            count += 1

        avg_length = total_length / count if count > 0 else 0.0
        avg_width = total_width / count if count > 0 else 0.0
        avg_thickness = total_thickness / count if count > 0 else 0.0

        return overlay, count, avg_length, avg_width, avg_thickness

    def draw_polar_lines_with_metrics(base_img, binary_edges, lines, color=(255, 0, 0)):
        overlay = base_img.copy()
        if lines is None or len(lines) == 0:
            return overlay, 0, 0.0, 0.0, 0.0

        count = 0
        total_length = 0.0
        total_width = 0.0
        total_thickness = 0.0

        for line in lines:
            rho, theta = line[0]
            a = np.cos(theta)
            b = np.sin(theta)
            x0 = a * rho
            y0 = b * rho

            x1 = int(x0 + 10000 * (-b))
            y1 = int(y0 + 10000 * (a))
            x2 = int(x0 - 10000 * (-b))
            y2 = int(y0 - 10000 * (a))

            cv2.line(overlay, (x1, y1), (x2, y2), color, 2)

            mask_line = np.zeros_like(binary_edges)
            cv2.line(mask_line, (x1, y1), (x2, y2), 255, 1)
            intersection = cv2.bitwise_and(binary_edges, binary_edges, mask=mask_line)

            active_pixels = np.column_stack(np.where(intersection > 0))
            if len(active_pixels) > 1:
                pts = active_pixels[:, [1, 0]]
                dists = [np.linalg.norm(pts[i] - pts[j]) for i in range(len(pts)) for j in range(i+1, len(pts))]
                line_len = max(dists) if dists else 0.0
            else:
                line_len = 0.0

            line_area = np.sum(intersection > 0)
            line_width = line_area / line_len if line_len > 0 else 0.0
            line_thick = line_width

            total_length += line_len
            total_width += line_width
            total_thickness += line_thick
            count += 1

        avg_length = total_length / count if count > 0 else 0.0
        avg_width = total_width / count if count > 0 else 0.0
        avg_thickness = total_thickness / count if count > 0 else 0.0

        return overlay, count, avg_length, avg_width, avg_thickness

            if lines_polar is None or len(lines_polar) == 0:
                print(f"  -> [NOTE] Insufficient continuous alignment for this angle segment.")

Sustainable Development Goals mapping

  

    
SDG 9 · Industry, Innovation and Infrastructure

      
Early crack detection supports resilient infrastructure (target 9.1) and a low-cost, GPU-free inspection method is an innovation that smaller agencies can adopt (target 9.5). The pipeline classifies bridge decks, pavements and walls and runs on a Raspberry Pi.

    
SDG 11 · Sustainable Cities and Communities

      
Cracks are the first sign of structural deterioration in buildings, roads and bridges. Frequent automated screening, including drone footage, helps cities find and repair damage before it becomes a safety hazard, which supports safe and resilient settlements.
