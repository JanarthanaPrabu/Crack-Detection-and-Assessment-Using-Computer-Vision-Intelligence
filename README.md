# Crack-Detection-and-Assessment-Using-Computer-Vision-Intelligence
Crack detection and assessment using computer vision. Phase 1: benchmark of classical feature descriptors (HOG, GLOH, SURF, BRISK, MSER, Shi-Tomasi) with SVM, Random Forest, XGBoost and Decision Tree on SDNET2018. Phase 2: UAV-GCD crack annotations. Plus an edge and Hough pipeline. M.Tech project, Amrita School of Computing.
